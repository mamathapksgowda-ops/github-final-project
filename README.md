# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple project that calculates the interest earned or paid on a principal amount using the annual interest rate and time period.

## Formula
**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest in percentage.
- **Time:** The time period in years.

## Example
Suppose:
- Principal = 1000
- Rate of Interest = 5%
- Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

Total Amount = Principal + Simple Interest = 1100
